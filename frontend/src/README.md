# TaskFlow - Full Stack To-Do List Application

## Project Description

TaskFlow is a full-stack To-Do List application developed using React.js, Django REST Framework, and MySQL.

The application helps users manage their daily tasks by adding, editing, deleting, searching, and completing tasks.

## Technologies Used

- React.js
- Django
- Django REST Framework
- MySQL
- Axios
- HTML
- CSS
- JavaScript
- Git & GitHub

## Features

- User Registration
- User Login
- Add Tasks
- View Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed/Pending
- Search Tasks
- Dashboard
- Form Validation
- Logout
- Responsive UI
